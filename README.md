# CSVレスキュー v4 — 指定列での重複削除（2026年10月）

公開先: https://csv-rescue-tool.pages.dev/

## v4で追加したこと
- データ行の重複削除を「行全体の一致」または「指定した列の一致」で切り替えられます。
- 指定列は `3`、`1,3` のように入力し、複数列を組み合わせて比較できます。
- 重複があった場合は「最初の行を残す」「最後の行を残す」を選べます（行の元の順番は維持）。
- 判定列が全て空欄の行は消さずに残します。比較は厳密一致（大文字小文字区別、空白は「前後の空白を削除する」設定に従う）。
- 「出力予定」の中に重複削除数を表示。列番号が誤っている場合はダウンロードを無効化します。
- 指定列での重複削除の解説ページ（csv-dedupe-by-column.html）と、テスト用 sample-dedupe.csv を追加。サイトマップ・内部リンクも更新。

## v3の機能を維持
- CSV/TSVの読み込み・変換、文字コード自動推定、UTF-8（BOM付き／なし）出力。
- CSV行列数チェック、重複・空行・空列の診断、列抽出・並べ替え、短い行の補完、Excel数式保護。
- プライバシーポリシー・問い合わせ先・Google Search Console認証メタタグ、AdSenseコード、ads.txt。

## GitHubへのアップロード
1. 念のため既存のGitHubリポジトリで **Code → Download ZIP** からバックアップを取ります。
2. このZIPを解凍し、フォルダの **中にある全ファイル** をGitHubのリポジトリ最上位にアップロードします（ZIP自体、外側のフォルダはアップロードしない）。
3. 同名ファイルは更新、`csv-dedupe-by-column.html` は新規追加。「Commit changes」で保存します。
4. Cloudflare Pagesの最新デプロイがSuccessになることを確認します。
5. ブラウザでCtrl+Shift+Rで再読み込みし、`sample.csv` で下記のテストを実施してください。

## 手動テスト
1. `sample.csv` で診断。元データの重複が1件と表示される。
2. 「重複したデータ行を削除する」を選択。「行全体が完全一致」で削除予定1件。
3. 判定方法を「指定した列の値が一致」にして列番号 `3` を入力。削除予定1件。
4. 不正な列番号 `5` を入力すると、エラーになりダウンロードできない。
5. `sample-dedupe.csv` を読み込み、重複判定列を `2` に設定。最初の行を残す場合は佐藤さんのポイント100、最後ならポイント300が残ることを確認。
6. 空欄キー行が自動削除されないことを確認してください。
7. `/ads.txt` と `/sitemap.xml`、`/csv-dedupe-by-column.html` が開けるか確認してください。

## 注意事項
- 行の同一性は厳密一致であり、別表記・メール大文字小文字・全角半角などを自動正規化しません。
- 同じキーでも別の注文履歴や人物の可能性があります。重複削除は値の統合・合計をせず、指定行を除外する処理です。
- 判定は列抽出前に行い、元ファイルの列番号で指定します。処理対象のCSVは元のまま保存しておいてください。
- 文字化け・列ズレを自動で完全修正する機能ではありません。
- AdSenseの審査結果、検索流入、収益を保証しません。
