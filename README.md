# CSVレスキュー（初期MVP）

無料で公開するための、HTML/CSS/JavaScriptだけで動くCSV診断ツールです。

## 機能
- CSVをブラウザ内で読み込み（最大20MB）
- UTF-8 / Shift_JIS系の文字コードを指定して読み込み
- 行ごとの列数不一致、空・重複ヘッダー、重複行、空行を診断
- UTF-8 BOM付き/なしCSVとしてダウンロード
- オプションでセル前後の空白削除、完全一致の重複行削除
- サーバー側のアップロード機能なし

## ローカルで確認
1. ZIPを展開します。
2. `index.html` をChromeまたはEdgeで開きます。
3. CSVファイルを選んで診断し、プレビューとダウンロードを確認します。

## Cloudflare Pagesで公開する手順
1. GitHubに新しいリポジトリを作り、このフォルダ内のファイルをアップロードします。
2. Cloudflareにログインし、Workers & PagesからPagesプロジェクトを作成します。
3. GitHubリポジトリを接続します。
4. 静的サイトとして設定します。ビルドコマンドは不要、出力ディレクトリはリポジトリのルート（`/` または空欄）にします。
5. 公開されたURLでPC・スマートフォンから動作確認します。

画面や設定名はサービス更新により変わる場合があります。Cloudflareの公式手順も確認してください。

## 公開前に必ず行うこと
- お手持ちの実データではなく、個人情報を含まないテストCSVで十分に確認する。
- 「自動判定」「修復」がすべてのファイルで正しく動くとは説明しない。
- `contact.html` の問い合わせ案内を、実際に使える連絡先やフォームに置き換える。
- プライバシーポリシーを、実際に導入するアクセス解析・広告サービスに合わせて更新する。
- AdSenseの審査通過や収益を保証しない。広告申請前に公式要件を確認する。

## 既知の制限
- Shift_JIS系の読み込みはブラウザのTextDecoder実装に依存します。
- 文字コードの自動判定は推定で、完全ではありません。
- 複雑なCSVの方言や不正な引用符を含むデータには対応できない場合があります。
- 「列数不一致」は問題の位置を知らせるもので、自動的に正しい値へ修復する機能ではありません。
- この初期版には広告コード、解析コード、バックエンドは含まれていません。
