# CSVレスキュー v6 — 2つのCSV差分比較ツールを追加

サイト: https://csv-rescue-tool.pages.dev/  
新ページ: https://csv-rescue-tool.pages.dev/csv-compare.html

## v6で追加したもの
- **CSV差分比較ツール** `csv-compare.html`：2つのCSV/TSVを選択し、追加・削除・変更を判定。
- **キー列比較**：IDなど一意の列を指定すると、同じキーの行の変更を表示（キーは空欄・重複不可）。
- **行全体比較**：行順に左右されず、重複行の個数も含めて追加・削除を検出。変更は追加＋削除として表示。
- **差分レポート**：差分全件をBOM付きUTF-8のCSVでダウンロード。Excelの数式として解釈される可能性がある値をエスケープ。
- **個別文字コード設定**：変更前・変更後それぞれでUTF-8/Shift_JIS、自動区切り文字判定を選択可能。
- 新しいテスト用の `sample-before.csv` と `sample-after.csv`、`compare-core.js`、`compare-ui.js` を追加。
- サイトのトップページにv6へのリンク、説明、FAQを追加。サイトマップも更新。
- v5までの全機能、AdSenseコード、Google確認タグ、`ads.txt`、お問い合わせ先を維持。

## GitHubとCloudflare Pagesへの更新手順
1. [GitHubのリポジトリ](https://github.com/rexsf7/csv-rescue-tool) の Code → Download ZIP で念のためバックアップ。
2. v6配布ZIPを解凍し、**フォルダ内のファイルすべて**をリポジトリのルートにアップロード（ZIP自体をアップロードしない）。
3. 既存ファイルを置き換え、新規ファイルを追加して Commit changes。
4. Cloudflare Pagesで最新デプロイが Success になったらトップページと `csv-compare.html` を開く。
5. Google認証やAdSenseは再設定不要。審査結果は引き続きAdSense画面で確認。

## 動作テスト（おすすめ）
1. 差分比較ページを開き、変更前に `sample-before.csv`、変更後に `sample-after.csv` を選択。
2. 比較方法は「キー列（IDなど）で比較」、キー列番号は `1`。
3. **追加1件、削除1件、変更1件、一致2件**となれば基本動作OK。
4. 差分CSVをダウンロードし、状態やメールアドレスの変更が記録されているか確認。
5. 「行全体が一致するか比較」を選ぶと **追加2件、削除2件、変更0件、一致2件**。
6. 同じファイル同士なら差分0件。空欄・重複キーがある場合はエラーとする。
7. Shift_JISの比較をする場合は、ファイルごとに正しい文字コードを指定する。

## 仕様上の制限
- 1ファイル20MB以下、データ10万行以下（双方それぞれ）。PCのメモリが十分でないと比較できない場合があります。
- **両CSVの見出し名と列順が完全に一致する必要があります。** 列ズレを検出したときは中断します。
- 比較は文字列の厳密一致。前後の空白、大文字小文字は区別します。
- 同一キーでも内容が変われば「変更」、キー自体が変われば「削除＋追加」です。
- 行の移動だけでは差分に含めません。結果には一致行を含めず、差分のプレビューは最大50件です。
- CSVはブラウザ内のみで読み込み、サーバーに送信しません。差分レポートの数式対策は元データを修正しません。
- 広告審査合格や収益、検索順位は保証されません。
