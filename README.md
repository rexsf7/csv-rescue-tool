# CSVレスキュー 改良版 v2

https://csv-rescue-tool.pages.dev/

## 追加した機能
- UTF-8 / Shift_JIS（Windows-31J）の読み込み、UTF-8 BOM付き/なし出力
- CSVに加えてタブ区切りTSV / セミコロン区切りの読み込み（出力はCSV）
- 重複行、空白行、空列の検出・任意削除
- 空白・重複するヘッダー名の任意補正
- 短いデータ行の末尾への空欄追加（任意・意味上の列ズレの修復ではない）
- 前後の空白削除／Excelで数式として解釈される可能性のあるセルの保護（任意）
- プレビュー、出力予定の行数・列数表示、よくあるトラブルの解説3ページ
- 更新済みのサイトマップ・robots.txt
- 問い合わせ先 `csvrescue.help@outlook.jp` を設定
- **既存の Google Search Console 所有権確認の meta タグを保持**

## GitHubで公開サイトを更新する方法（現在のユーザー向け）
1. ZIPを解凍し、`csv_rescue_v2` フォルダを開いてください。
2. GitHubの https://github.com/rexsf7/csv-rescue-tool を開きます。
3. 「Add file」→「Upload files」（ファイルを追加→ファイルをアップロード）を開きます。
4. ZIP **そのものではなく、中のファイルすべて** をドラッグ＆ドロップします。`index.html`、`app.js`、`style.css` などは既存ファイルと同じ名前で、**リポジトリの一番上の階層**に配置してください。
5. 変更内容を確認し「Commit changes」で保存します。既存のファイルは上書きされます。途中でブラウザを閉じないでください。
6. Cloudflare PagesがGitHubの変更をデプロイしたら https://csv-rescue-tool.pages.dev/ を開き、診断・保存を確認します。

**重要：GitHubの既存ファイルと同名ファイルを、Web画面のUpload filesで一括上書きできない／競合になる場合があります。その場合はWebの編集画面でファイルごとに貼り替えるか、GitHub Desktop等で更新してください。GitHubで反映されているのを確認してからサイトを検証してください。**

### 念のためのバックアップ
変更前にGitHubの「Code」→「Download ZIP」で現在の状態を保存しておくことをおすすめします。

## テスト
1. `index.html` をChrome / Edgeで開き、`sample.csv` を診断する。
2. 重複行が1件見つかることを確認する。
3. 「重複行を削除」「空白行を削除」などをチェックして出力予定を確認する。
4. UTF-8 BOM付きでダウンロードして、Excelなどで文字と列構造を確認する。
5. `csv-mojibake.html` などの解説ページや `contact.html` のリンクを確認する。
6. `sitemap.xml` と `robots.txt` が公開URLで開けるか確認する。

## 制限・注意
- 最大20MB、基本的なCSV/TSV形式を扱うブラウザ用ツールです。
- 文字コードは完全自動判定ではなく推定です。自動判定が正しくないこともあります。
- 元ファイルを破壊しませんが、ダウンロードしたCSVは選んだオプションにより内容が変わります。
- 列ズレの正解や壊れた日本語をすべて復元する機能はありません。
- ブラウザでファイルを処理し、ファイル内容をWebサーバーにアップロードしません。
- 広告タグ・アクセス解析タグは未導入です。導入する場合はプライバシーポリシーや同意管理を見直してください。
- Search Consoleに登録済みでも検索流入やAdSense承認・収益は保証されません。
