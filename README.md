# CSVレスキュー v3 — 改良版（2026年10月）

公開先: https://csv-rescue-tool.pages.dev/

## 新しい機能
- 入力区切り文字の推定（カンマ／タブ／セミコロン）。誤判定時は手動指定可能
- CSV（カンマ）／TSV（タブ）の出力形式を選択可能
- 指定列の抽出・順番変更（例: `1,3`、`3,1`、`2-4`）
- 出力予定の行数・列数・形式を表示。列番号が不正なときダウンロードを無効化
- 使い方の解説ページを2つ追加し、サイトマップと内部リンクを更新
- Google AdSenseのコード／`ads.txt`、Search Console認証用メタタグ、お問い合わせ先を保持
- プライバシーポリシーのGoogle広告・Cookieの記述を追加

## 今までの機能も維持
- UTF-8／Shift_JIS系CSVの読み込み
- UTF-8 BOM付き／なしの保存
- 列数不一致、重複行、空白ヘッダー、空行・空列の診断
- 空行・重複行・空列の削除、空のヘッダー補正、短い行の末尾の補完
- ブラウザ内処理、20MBまでの読み込み

## 公開前のチェック
1. GitHubの元の状態を **Code → Download ZIP** でバックアップする。
2. ZIPを解凍して **中のファイルだけ** をリポジトリの最上位にアップロード・コミットする。`csv_rescue_v3` フォルダを階層として作らないこと。
3. GitHubの `index.html` にGoogle認証タグとAdSenseタグが残っていることを確認する。
4. Cloudflare PagesのデプロイがSuccessになったら公開サイトを表示する。
5. `sample.csv` で重複1件を確認する。新しい出力形式を「TSV」にしてDLできることを確認。
6. 列番号 `1,3` で名前／メールだけが出力され、`3,1` で逆順にできることを確認する。
7. 列番号 `5`（サンプルの列数は3）では、エラーが出てDLボタンが無効になることを確認。
8. `/ads.txt` と `/sitemap.xml` が公開URLで開けることを確認する。
9. `/csv-to-tsv.html` と `/csv-extract-columns.html` が公開されることを確認する。

## 必ず読んでほしい注意
- 文字コードおよび区切り文字の自動判定は推定です。必ずプレビューを確認してください。
- 意味上の列ズレ、元データ破損、失われた文字は自動で直せません。
- 列を抽出すると、指定していない列は出力ファイルから除外されます。元ファイルを保管してください。
- 数式保護の機能は値を書き換えるため必要な場合のみ使用してください。
- このZIPは、広告審査合格・検索上位・収益を保証しません。
- AdSenseのプライバシー要件や配信先地域の同意義務を公開前に確認してください。広告利用に関する実際の設定とプライバシーポリシーの記述を一致させる必要があります。
